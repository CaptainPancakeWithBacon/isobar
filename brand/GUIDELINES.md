# Isobar logo guidelines

## The idea

The pill from the bar, ringed by contour lines like ripples. Nested stadiums read as isobars on a weather map. The `o` in the wordmark repeats the ring.

## Files

| File | Use |
| --- | --- |
| `isobar-symbol.svg` | Master symbol, three rings and the pill. 48 px and up. |
| `isobar-symbol-small.svg` | Two rings and the pill. 24 to 48 px. |
| `isobar-favicon.svg` | One ring and the pill. Below 24 px: favicon, tab icon, tray icon. |
| `isobar-horizontal.svg` | Symbol and wordmark side by side. The default logo. |
| `isobar-stacked.svg` | Symbol above the wordmark. For square spaces. |
| `symbol/`, `horizontal/`, `stacked/` | Black, white and ink versions, PNGs, square avatar, app icon, web icon set. |
| `board/board.html` | Presentation board with mockups. Open it in a browser. |

The masters are filled outlines. They contain no live text and no strokes.

## Colour

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0F2F33` | The logo on light backgrounds, the bar, tiles. |
| Paper | `#EAF4F0` | The logo on ink. |
| Ground | `#C8E0D8` | Backgrounds. |

Contrast: ink on paper 12.7 to 1, ink on ground 10.2 to 1. Pantone and CMYK values are not set yet. Match them by eye when printing and write them down here.

One-colour versions exist in black and white. The logo never takes an accent colour.

## Clear space

Keep a margin around the logo equal to the height of the pill, which is one eighth of the symbol's height.

## Minimum size

| Version | Minimum |
| --- | --- |
| Horizontal lockup | 120 px wide |
| Stacked lockup | 80 px wide |
| Symbol | 48 px |
| Small cut | 24 px |
| Favicon cut | 16 px |

## Don't

- Don't stretch, rotate or recolour the logo.
- Don't use the three-ring symbol below 48 px, use the small or favicon cut.
- Don't put the ink logo on a dark background, use the white version.
- Don't set the wordmark in another font. It is Inter Display SemiBold with a drawn ring for the `o`, already turned into paths.
